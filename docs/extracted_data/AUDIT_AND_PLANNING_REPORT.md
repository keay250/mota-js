## 3. 后续基于真值库的自动化移植流水线规划

有了这份真值库之后，后续移植将彻底摆脱手动查漏，进入**全自动化流水线阶段**：

1. **怪物数据自动注入**：任何楼层直接按 `map_xxx.json` 自动生成，怪兽数值 1:1 读取 `enemies_truth_table.json`，0% 人工录入误差。
2. **机关门与 autoEvent 自动编译**：解析器直接从 `special_doors` 生成包含战后联动、撞门兜底与跨层补偿的闭环代码。
3. **传送拓扑自动缝合**：基于 `teleport_network.json` 自动配置 `changeFloor`，杜绝任何断路死胡同。
4. **NPC 对话一键转成魔塔气泡**：从 `npcs` 中的 `dialogue` 列表自动生成 `core.drawText` / `_clickAction_text` 事件流。
