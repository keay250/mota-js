## 5. 城镇系统在 Mota-js 中的落地架构设计

1. **大地图视口架构**：厄泽城 (75x75) 与王都 (93x45) 超出魔塔默认 15x15 视口，采用魔塔动态摄像机跟随（`core.setViewport` / `bigmap` 模式），保持宏伟的城市探索感。
2. **统一商店面板插件**：基于提取的 `shops` 货品真值，直接对接魔塔的自定义商店插件 (`quickShop` / `customShop`)，支持买卖与神装锻造。
3. **NPC 气泡与立绘对话系统**：基于提取的 `dialogue_tree`，实现多轮推进、选择支判定以及剧情任务开关无缝衔接。
