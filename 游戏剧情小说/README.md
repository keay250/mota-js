## 一、这是什么

这不是同人创作，而是**游戏内文本的忠实整理**：

- **对话原文一字不改** —— 所有 `**角色**：台词` 都是从 `Data\Map*.rxdata` 的事件指令里原样提取的。
- **只做了三类编辑**：① 删掉非剧情内容（见 §五）② 合并对话框的硬折行 ③ 加上场景小标题与必要的位置标记。
- **没有编造任何剧情** —— 每一章都由脚本做「双向逐字校验」：输出里的每个字都能回溯到原文，原文里的每条剧情也都在输出中。

## 五、清洗规则（删了什么、留了什么）

**删除**（这些不是剧情）：
1. 操作提示（"按 X 键"、"使用 XX"、"点击"、存档/读档/ESC）
2. 商店、交易、合成、附魔等系统文本与价格
3. 系统与规则说明（难度、作弊模式、成就、挑战模式、玩家辅助装置）
4. 制作者的开发笔记（"请复制本事件"、"0 层就用这张地图改"等）
5. 纯数值反馈（"生命值-2"）、纯符号行、完全重复的提示（只保留首次）

**保留（一字不改）**：
1. **角色之间的对话**
2. **剧情旁白与环境描写**
3. **影响剧情走向的选项**

**技术性处理**（不算改动原文）：
- **合并对话框硬折行**：原文按对话框宽度（约 16 全角字）硬拆行，拆分点常落在词中间（如"漫长的／岁月"），已还原为完整句子
- **去掉角色名的编号前缀**：`0-恐怖利刃` → `恐怖利刃`（数字是引擎的事件槽位编号）
- **还原"伪影冒号"**：导出时正文首行可能被误当成说话人，形成 `在某某的引领下，：他走进了城门` 这样的假冒号，已按语义还原
- **保留原文控制符**：`\v[n]`（变量）、`\c[n]`（颜色）、`\s[n]`（停顿）等原样保留
- **保留原文笔误**：如"神不知鬼绕到"、"都还没有技能的可+是大有人"等，一律照抄不改

## 七、已知限制

1. **图片里的文字**（部分 UI 提示）不在数据文件中，无法提取。
2. **脚本动态拼接的字符串**（如 `"第" + n + "章"`）无法静态还原。
3. **说话人归属**：少数行在原文中没有名字窗口，小编们按上下文推断（如把"若是我执意要带人进去呢？"归给训蛇士）；无法确证的一律保留 `？？？`，不擅自起名。
4. **顺序微调**：极少数事件在原数据中的排列与剧情因果不符（如"战败台词"排在"交战"之前），个别章节做了微调并在该章说明中标注。
5. **边界判断**：少数文本介于"剧情"与"系统提示"之间（如"附魔需要一万金币"既是价格也是剧情博弈），处理原则是**从宽保留剧情**。
